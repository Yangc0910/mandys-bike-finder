# PRD v0.1 — Initial iOS App Concept

Status: Historical  
Primary platform direction at the time: iOS app  
Current status: Superseded by the Web MVP direction

## Summary

The original idea was to build an iOS app that could eventually be published on the Apple App Store. The broader goal was not only to ship an app, but also to build a portfolio product and learn the software product development process from idea discovery through PRD writing, implementation, iteration, and release.

## Initial Broad Product Directions

Several possible product directions were considered:

- Local marketplace deal scout.
- DIY project planner.
- Kids bike fit advisor.
- Local negotiation message helper.
- Digital health product canvas.

These ideas shared a common theme: helping a real person make a better everyday decision with lightweight software support.

## First Specific App Direction

The first specific app direction selected was a used kids bike advisor. This direction had a concrete personal story, a clear target user, and an easy-to-understand decision problem: parents often see a used kids bike listing but do not know whether it is the right size, a fair price, or worth messaging the seller about.

## Core Initial Features

The early iOS concept included:

- Child-to-bike size advisor.
- Used bike listing analyzer.
- Screenshot upload.
- Seller questions and message generation.

## Why It Changed

The iOS direction was too heavy for the first MVP. App Store setup, App Store review, signing, device testing, and native UI decisions could slow down learning and iteration. A web app would allow faster product validation, easier sharing, and simpler implementation of listing input, screenshot upload, and future price reference checks.
