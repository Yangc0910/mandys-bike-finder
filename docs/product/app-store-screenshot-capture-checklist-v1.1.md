## 1. Safety Boundary

The screenshot fixture is activated only when both variables are explicitly enabled:

```text
NEXT_PUBLIC_APP_STORE_MVP_MODE=true
NEXT_PUBLIC_APP_STORE_SCREENSHOT_FIXTURE_MODE=true
```

The fixture:

- Uses only fictional child, listing, location, and seller-message data.
- Does not write to or clear the user's localStorage.
- Does not call AI, extraction, marketplace, report, or email APIs.
- Generates result and History statuses through the current local analysis functions.
- Is selected only by `?screenshotFrame=1` through `?screenshotFrame=6`.

Never enable `NEXT_PUBLIC_APP_STORE_SCREENSHOT_FIXTURE_MODE` on the production `app.mandysbikefinder.com` deployment. Use a temporary protected preview deployment and remove it after final capture.

## 5. Point The Native Shell At Preview

The Capacitor config uses production by default. For screenshot work only, override it without editing the committed URL:

```bash
cd app
CAPACITOR_SERVER_URL="https://YOUR-PREVIEW-URL.vercel.app" npm run cap:sync
npm run cap:open:ios
```

Confirm the generated native configuration points to the temporary HTTPS preview. Do not commit generated URL changes, and do not archive or submit a build that points to the preview.

After capture, restore production configuration:

```bash
cd app
npm run cap:sync
```

Then confirm the server URL is again `https://app.mandysbikefinder.com`.

## 6. Simulator Setup

Use a 6.9-inch iPhone simulator that produces an Apple-accepted native portrait size. Keep the same simulator, appearance, locale, and status bar for all six frames.

Recommended controls:

- Appearance: Light
- Orientation: Portrait
- Text size: Default
- Display zoom: Default
- Language: English
- Region: United States
- Time: `9:41`
- Battery: `100%`
- Wi-Fi and cellular signal: full
- Keyboard: dismissed
- Notifications and permission prompts: cleared

Optional status-bar override:

```bash
xcrun simctl status_bar booted override \
  --time 9:41 \
  --batteryState charged \
  --batteryLevel 100 \
  --wifiBars 3 \
  --cellularBars 4
```

Clear the override after capture:

```bash
xcrun simctl status_bar booted clear
```
