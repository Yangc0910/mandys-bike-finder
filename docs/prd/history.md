# PRD Version History

This file records meaningful PRD changes. Archived full versions live in `docs/prd/versions/`.

## v0.4 - 2026-05-10

Status: Current baseline

v0.4 defines Mandy's Bike Finder as a personal-use listing assistant and documents the current local Python prototype. The baseline includes headed browser collection, YAML-configured sources, filtering, scoring, selection, SQLite deduplication, and Gmail summaries.

Key product decisions captured in this version:

- The product remains conservative and visible-browser based.
- Scoring ranks opportunities but does not trigger automated buying or messaging.
- The repository is the system of record for PRD, decisions, prompts, and future app code.
- The current implementation is treated as a prototype foundation, not the final app experience.
