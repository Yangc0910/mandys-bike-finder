## 1. Product Thesis

Version 1.3 should make the App Store experience feel more like a native app on first open and easier to understand at a glance.

The release adds a short startup entry screen, more icon-led guidance, and a clearer visual path through Profile, Evaluate, and History. It does not add accounts, cloud sync, payments, push notifications, marketplace automation, or a required login.

## 2. Scope

- Show a short App Store-mode startup screen using the app launch artwork.
- Let users continue without an account while the startup screen auto-dismisses after a short delay.
- Add persistent visual flow guidance for Rider, Listing, and Saved steps.
- Add icons to major app headers, input choices, form groups, recommendation actions, saved-history sections, and settings controls.
- Keep screenshot fixture mode fast and deterministic by skipping the startup wait.
- Advance visible App Store version metadata to `1.3` and iOS build metadata to `1.3 (6)`.

## 3. Guardrails

- No initial LLM, email, marketplace, or account request on app launch.
- No new required user account or login dependency.
- Existing Profile, Evaluate, History, Settings, Privacy, and offline flows remain compatible.
- Existing App Store screenshot fixture routes remain available for automated capture.

## 4. Release Checks

- Run automated tests.

- Run App Store-mode browser verification and confirm the startup screen, main app shell, and Settings version render correctly.
