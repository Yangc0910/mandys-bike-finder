# Mandy's Bike Finder Version 1.2 Reliability And Chinese Localization PRD

Version: 1.2

Status: In implementation

Date: 2026-06-13

Production baseline: version 1.1

Working branch: `codex/v1.2-history-i18n`

## 1. Product Thesis

Version 1.2 should strengthen the two behaviors that make the app worth returning to:

1. Parents can trust that each bike they save will remain available as a separate decision.
2. Chinese-speaking parents can complete the full App Store workflow without being pushed back into English.

This is a reliability and reach release, not a business-model expansion.

## 2. Confirmed User Problem

Real app use exposed a History defect:

- Two different listings with similar title, price, brand, wheel size, platform, and result status could be treated as duplicates.
- Model, location, link, condition, and description were not part of the previous identity rule.
- Saving the second listing updated and moved the first record instead of creating another saved decision.

The expected product behavior is:

- Different listings remain separate, including listings that look similar at a glance.
- Re-saving the exact same evaluation does not create accidental duplicates.
- History cards expose enough secondary information to distinguish similar listings.

## 3. Version 1.2 P0 Scope

### History Reliability

- Compare complete listing snapshots when determining whether a save is an exact duplicate.
- Include model, location, link, condition, description, bike type, color/style, input mode, and rider snapshot.
- Keep the existing 10-record local History limit.
- Preserve favorite state when an exact duplicate is moved to the top.
- Show model and location on History cards when available.
- Keep existing version 1.0 and 1.1 local data readable without migration.

### Simplified Chinese

- Support `English` and `简体中文`.
- Default to Simplified Chinese when the device/browser language begins with `zh`, unless the user has made an explicit language choice.
- Persist language choice locally on the device.
- Localize the four main tabs: Profile, Evaluate, History, and Settings.
- Localize core fit/value/risk results, standard seller messages, dates, wheel sizes, riding experience, validation, and status feedback.
- Localize Privacy and offline recovery pages.
- Keep stored Profile and History data language-neutral and compatible across language changes.

### Quality

- Add automated tests for similar-listing separation and exact-repeat deduplication.
- Add automated tests for language resolution and core analysis translation.
- Pass lint, type checking, production build, and mobile browser regression.

## 4. Release Guardrails

- No account or cloud sync.
- No payment, subscription, or Bike Scout launch.
- No automatic marketplace scraping.
- No AI request on app launch or language change.
- Language preference remains local and is not erased by Profile/History clearing.
- Existing local Profile and History keys remain compatible.
- Public web MVP behavior remains separate from App Store mode.

## 5. Recommended P1 Follow-Ups

These are strong candidates only if P0 remains stable:

1. Add a lightweight two-bike comparison view using saved snapshots.
2. Add History sorting for newest, shortlist first, and recommendation status.
3. Let users add a private nickname such as `Blue Trek near school`.
4. Add a one-tap seller inspection checklist from each saved item.
5. Improve Chinese terminology through review by native-speaking parents, especially fit and safety language.

## 6. Explicit Non-Goals

- User accounts or multi-device sync.
- Unlimited or server-backed History.
- Marketplace monitoring or automated alerts.
- Payments or subscriptions.
- New AI providers or major scoring changes.
- Broad social sharing before privacy and usefulness are validated.

## 7. Success Signals

Without adding analytics as a release dependency, evaluate:

- Users can save at least three similar listings and reopen each correct snapshot.
- Exact repeat saves do not inflate History count.
- Chinese users can complete Profile, Evaluate, Result, Save, History, Settings, Privacy, and offline recovery without blocking English-only UI.
- Existing version 1.1 local data remains readable after update.
- Support reports about missing or overwritten saved bikes stop recurring.

Future privacy-reviewed analytics could measure:

- Percentage of active devices using Chinese.
- Evaluation-to-save conversion.
- Percentage of devices with two or more saved bikes.
- History revisit rate.
- Shortlist usage and comparison intent.
