## Summary

Mandy's Bike Finder is a personal listing assistant for finding promising bike listings from sources the user already accesses manually. It monitors configured pages in a visible browser, extracts visible listing details, ranks new opportunities, deduplicates seen links, and sends a Gmail summary.

## In Scope

- Headed Playwright browser with persistent user profile.
- Manual user login.
- YAML-configured listing sources.
- Optional source-specific selectors.
- Visible-link fallback extraction.
- Keyword and price filters.
- Configurable 0-100 scoring.
- Primary-source-aware top-N selection.
- Local SQLite seen-link storage.
- Gmail send-only summaries.

## Out of Scope

- Automated login.
- CAPTCHA, paywall, bot-check, or access-control bypass.
- Auto-messaging sellers.
- Auto-buying.
- Public marketplace features.
- Full future app UI.

## Product Principles

- Assist the user's judgment.
- Prefer transparent configuration over hidden behavior.
- Keep sensitive state local.
- Use conservative pacing.
- Treat safety and website access boundaries as product requirements, not implementation details.
