# Version 1.0.0 App Store Release

Release status: Production baseline

App Store version: `1.0`

Git tag: `v1.0.0-app-store-release`

Baseline commit: `ed6a548`

Recorded: 2026-06-10

## Release Summary

Mandy's Bike Finder version 1.0 is the first production App Store release. It is the stable baseline for all post-launch work. Version 1.1 and later changes must be developed away from this tag and must preserve the shipped core experience.

Production surfaces:

- Public web MVP: `https://www.mandysbikefinder.com`
- App Store hosted app: `https://app.mandysbikefinder.com`
- iOS app shell: Capacitor hosted-app strategy

## Shipped App Store Surface

- `Profile`: one locally saved child profile and a local wheel-size recommendation.
- `Evaluate`: screenshot, link/text, and manual listing input with an editable review step.
- `History`: locally saved evaluations, favorites, details, and delete controls.
- `Settings`: privacy and AI disclosures plus local data controls.
- Public `/privacy` and `/offline` routes.

## Production Guardrails

- Initial app load does not trigger OpenAI or another LLM.
- AI extraction requires an explicit user action.
- Local/manual analysis remains available when AI is unavailable.
- OpenAI, Resend, and other provider secrets remain server-side only.
- Marketplace scraping and login-gated automation are not part of the release.
- The public web MVP and App Store hosted app remain separate deployments/surfaces.

## Version Control Policy

- Treat `v1.0.0-app-store-release` as immutable.
- Treat `main` at the tagged commit as the version 1.0 production baseline.
- Do not move, recreate, or force-update the tag.
- Production hotfixes should branch from the production tag or current production `main`, use a narrow `hotfix/v1.0.x-*` branch, and receive their own patch tag after release.
- Version 1.1 work begins on `release/v1.1-ui-polish`.

## Verification Note

This release record reflects the confirmed App Store launch status supplied on 2026-06-10. Earlier repository status documents ended at TestFlight build `1.0 (3)` and should not be used to infer the newer App Store availability state.
