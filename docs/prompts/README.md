# Build Prompt Log

This folder stores meaningful prompts used to shape Mandy's Bike Finder. Prompts are part of the product record because they explain why the repository, docs, and future app evolved the way they did.

## Naming

Use:

```text
YYYY-MM-DD-short-topic.md
```

## Entry Format

Each prompt entry should include:

- Date
- Prompt summary
- Original user request when useful
- Output or implementation notes
- Follow-up decisions created by the work

Avoid storing secrets, credentials, private marketplace URLs, or OAuth tokens in prompt files.
